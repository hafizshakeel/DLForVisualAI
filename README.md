# DLForVisualAI

Welcome to the **DLForVisualAI** repository! Here, I share my insights and implementations of deep learning models, with a particular focus on visual data. While these implementations are based on my understanding, and there may be occasional mistakes, I ensure they are thoroughly tested before uploading. You can use these for learning, research, or other purposes.

Please note that due to limited time and computational resources, I am unable to fully train these models and compare their results with official implementations. I highly recommend using the pre-trained weights from the official sources for more accurate and reliable results.

## NN Basics
This section includes beginner-level implementations of various neural networks using PyTorch:

1. **Simple Fully Connected Network (NN)**
2. **Simple Fully Convolutional Network (CNN)**
3. **Transfer Learning** with pre-trained VGG16 and GoogLeNet models.

Features:
- Complete training setup, including:
  - Loading both online and custom datasets.
  - Defining paths for training, validation, and testing datasets.
  - Setting hyperparameters.
  - Training models and optimizing parameters.
  - Visualizing results using TensorBoard.
  
Future Plans:
- Adding code for model testing and metric computation.
- Expanding this setup for more complex neural network architectures.

## Generative Adversarial Networks
This section provides implementations of various Generative Adversarial Networks (GANs) using PyTorch, including __Simple GAN__, __DCGAN__, __WGAN__, __WGAN-GP__, __Pix2Pix__, __CycleGAN__, __ProGAN__, __SRGAN__, __ESRGAN__.

Most models include a basic training setup. Future updates will feature complete validation and testing setups, along with configurations similar to those in the NN Basics section.
